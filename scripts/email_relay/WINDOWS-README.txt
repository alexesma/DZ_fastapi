DZ EMAIL RELAY ДЛЯ WINDOWS
==========================

Программа отправляет письма из очереди DragonZap через обычную почту
с рабочего компьютера. Python и PowerShell не требуются.

ПЕРВЫЙ ЗАПУСК
-------------

1. Полностью распакуйте ZIP в отдельную папку, например:
   C:\DragonZapEmailRelay

2. Откройте config.json обычным Блокнотом.

3. Заполните:
   - relay_api_token: должен совпадать с EMAIL_RELAY_API_TOKEN на сервере;
   - адрес почты в smtp_accounts;
   - username: тот же адрес почты;
   - password: пароль приложения Яндекса, не обычный пароль;
   - telegram.bot_token, если нужна пересылка Telegram.

4. Сохраните config.json.

5. Запустите DZEmailRelay.exe двойным щелчком. Окно должно оставаться
   открытым. В нём появится строка «Релей запущен».

Если Windows показывает SmartScreen, нажмите «Подробнее» и
«Выполнить в любом случае». Сборка не имеет платной цифровой подписи.

ПРОВЕРКА И ОШИБКИ
-----------------

Журнал работы сохраняется в relay.log рядом с программой.
Если письмо не отправляется, пришлите последние строки relay.log.

Для остановки закройте окно программы.

ПЕЧАТЬ ЭТИКЕТОК И ДОКУМЕНТОВ
----------------------------

1. Установите принтеры обычным способом в Windows. Для принтера этикеток
   один раз задайте в настройках драйвера размер бумаги, например 58 x 40 мм.
   Для обычных документов задайте A4. Используется любое устройство,
   доступное через очередь печати Windows; модель заранее знать не нужно.

2. В config.json установите printing.enabled = true. machine_id можно
   оставить null: будет использовано имя компьютера. На нескольких
   компьютерах имена должны различаться. Чтобы задать постоянное имя,
   впишите его в printing.machine_id.

3. На дополнительных рабочих местах, которые нужны только для печати,
   поставьте email_enabled = false и telegram.enabled = false. Почтовые
   пароли на таких компьютерах не нужны. Сервисный relay_api_token нужен.

4. Перезапустите DZEmailRelay.exe. Команда
   DZEmailRelay.exe --check-printers показывает обнаруженные устройства,
   не подключаясь к серверу. Программа сообщит их имена в систему.

5. В DragonZap откройте Админ → Принтеры сотрудников. Назначьте каждому
   сотруднику доступные устройства отдельно для этикеток и документов A4,
   выберите основной принтер каждого типа. После этого печать из системы
   отправляется прямо в очередь Windows без диалога браузера.

Ошибки и ожидающие задания видны на странице принтеров и в relay.log.
Статус «Отправлено в принтер» означает приём задания очередью Windows;
физический выход листа зависит от принтера и его драйвера. Задания после
неопределённого результата автоматически не повторяются, чтобы не
создать дубли. Перед ручным повтором проверьте очередь и лоток принтера.

БЕЗОПАСНОСТЬ
------------

config.json содержит пароль почты и сервисный токен. Не отправляйте
заполненный config.json посторонним. Сам DZEmailRelay.exe секретов не
содержит.
