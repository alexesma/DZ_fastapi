DZ EMAIL RELAY ДЛЯ WINDOWS
==========================

Программа отправляет письма из очереди DragonZap через обычную почту
с рабочего компьютера. Python и PowerShell не требуются.

ПЕРВЫЙ ЗАПУСК
-------------

1. Полностью распакуйте ZIP в отдельную папку, например:
   C:\DragonZapEmailRelay

2. Откройте config.json обычным Блокнотом.

3. Заполните:
   - relay_api_token: должен совпадать с EMAIL_RELAY_API_TOKEN на сервере;
   - адрес почты в smtp_accounts;
   - username: тот же адрес почты;
   - password: пароль приложения Яндекса, не обычный пароль;
   - telegram.bot_token, если нужна пересылка Telegram.

4. Сохраните config.json.

5. Запустите DZEmailRelay.exe двойным щелчком. Окно должно оставаться
   открытым. В нём появится строка «Релей запущен».

Если Windows показывает SmartScreen, нажмите «Подробнее» и
«Выполнить в любом случае». Сборка не имеет платной цифровой подписи.

ПРОВЕРКА И ОШИБКИ
-----------------

Журнал работы сохраняется в relay.log рядом с программой.
Если письмо не отправляется, пришлите последние строки relay.log.

Для остановки закройте окно программы.

БЕЗОПАСНОСТЬ
------------

config.json содержит пароль почты и сервисный токен. Не отправляйте
заполненный config.json посторонним. Сам DZEmailRelay.exe секретов не
содержит.
